- Quantum Ring: room-temperature SU(3) quantum processor design
- LENR: coherent proton reassembly model
- STPC documentation: full theory summary

## Quick Start

1. Install Python 3.10+ with required packages:
   pip install numpy scipy matplotlib biopython scikit-learn pyvista plotly

2. Run GUI:
   python gui_unified.py

3. Fold a protein:
   python assemble_ubiquitin_fragment_ss.py

4. See HEARTBEAT file for current status.
