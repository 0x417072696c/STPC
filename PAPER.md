## 7. AllyFold: Fragment-Based Protein Structure Prediction

AllyFold is a non-ML approach to ab initio protein folding. It uses fragments extracted from a library of experimentally determined structures, excluding the target protein to avoid self-recognition.

### 7.1 Method

1. Extract all fragments of length 5 from a set of 211 PDB files.
2. For each window of the target sequence, select fragments with maximal sequence similarity.
3. Stitch selected fragments with overlap of 4 residues, minimizing overlap RMSD.
4. Scale the resulting chain by radius of gyration and align to the target structure using the Kabsch algorithm.

### 7.2 Results

| Protein   | Length | RMSD  |
|-----------|--------|-------|
| Trp-cage  | 20     | 3.34 Å |
| Villin    | 36     | 9.07 Å |
| Ubiquitin | 76     | 3.77 Å |

For ubiquitin, the core (residues 1–70) matches closely; the main deviation is the flexible C-terminal tail.

The method is deterministic, uses no neural networks, and requires no supercomputer.
